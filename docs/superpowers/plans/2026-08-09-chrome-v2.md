# Chrome v2 Implementation Plan (design-comp adoption)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adopt the approved design comps (vendored at `docs/design/2026-08-09-community-comps/`) across hal0-web: extended token set, ported site stylesheet, learn-IA nav with sub-nav, 56px header restyle, and the multi-column footer — all still fed by `nav.json` / `tokens.css`.

**Architecture:** The comp's `hal0-site.css` already resolves every value to CSS variables and uses our shipped palette. We port it as `src/styles/site.css` behind a `.site` scope with an alias block mapping unprefixed vars (`--bg`, `--fg-2`, `--accent-soft`, …) onto `--hal0-*` tokens, so the comp CSS lands near-verbatim and future comp iterations stay diffable. New tokens (status, device hues, extra fg/bg steps, radii, motion, letter-spacing) join `tokens.css` as `--hal0-*` canon. Nav manifest gains `sub` (section sub-nav) and `hidden` (pre-launch entries) fields.

**Tech Stack:** Astro 6, Starlight 0.39, Tailwind v4, node --test.

## Global Constraints

- Canonical values live in `src/styles/tokens.css`; where comp and tokens disagree, tokens win. Comp `.site` ramp already matches (`#0a0a0a`, `#141414`, `#050505`, `#f5f5f4`, `#c8c2bd`, `#a3a09c`, `#262626`, `#3a3a3a`, `#ffb000`).
- Design source of truth: `docs/design/2026-08-09-community-comps/` — `hal0-site.css` (styles), `site-chrome.jsx` (structure/behavior), `01 Unified Chrome.html` (specimens). Port structure faithfully; do not redesign.
- All chrome links continue to flow from `src/data/nav.json`. New nav schema fields: `sub?: NavLink[]` on header entries, `hidden?: boolean` (rendered nowhere while true), `external?: boolean` (↗ affordance).
- Nav labels lowercase mono. `npm run build && npm test` green after every task.
- Hidden-at-launch entries: `profiles` and `forum` header items ship in the manifest with `hidden: true` and flip on when their surfaces go live.

## File Structure

- `src/styles/tokens.css` — modified: status/device/elevation/motion/radius/letter-spacing tokens + `[data-theme='light']` block.
- `src/styles/site.css` — created: ported `hal0-site.css` with `.site` alias block; imported from `global.css`.
- `src/data/nav.json` — modified: learn IA (`learn` umbrella with `sub`), footer columns, hidden entries.
- `src/lib/nav.ts` — modified: schema types, `visibleHeader`, `footerColumns` accessors.
- `src/components/SubNav.astro` — created: 42px section sub-nav.
- `src/components/SiteHeader.astro` — created: comp header (56px bar, iconbtn cluster, filament) extracted from MarketingLayout so marketing + future standalone pages share it.
- `src/layouts/MarketingLayout.astro` — modified: uses `SiteHeader`.
- `src/components/SiteFooter.astro` — rewritten: brand column + 3 link columns + base line, per comp `Footer`.
- `src/components/StarlightSiteTitle.astro` — modified: visible-header links only.
- `scripts/test/nav.test.mjs`, `scripts/test/chrome-consistency.test.mjs` — modified for new schema/footer.

### Task 2: Nav manifest v2 + typed helpers

**Files:** `src/data/nav.json`, `src/lib/nav.ts`, `scripts/test/nav.test.mjs`

New manifest shape:

```json
{
  "header": [
    { "label": "learn", "href": "/docs/getting-started/", "match": "/docs", "exclude": ["/docs/reference/model-roster-benchmark"],
      "sub": [
        { "label": "docs", "href": "/docs/getting-started/", "match": "/docs", "exclude": ["/docs/reference/model-roster-benchmark"] },
        { "label": "blog", "href": "/blog", "match": "/blog" },
        { "label": "changelog", "href": "/changelog", "match": "/changelog" },
        { "label": "releases", "href": "/releases", "match": "/releases" }
      ] },
    { "label": "benchmarks", "href": "/docs/reference/model-roster-benchmark/", "match": "/docs/reference/model-roster-benchmark" },
    { "label": "profiles", "href": "/profiles", "match": "/profiles", "hidden": true },
    { "label": "forum", "href": "https://forum.hal0.dev", "external": true, "hidden": true }
  ],
  "footerColumns": [
    { "heading": "learn", "links": [docs, blog, changelog, releases] },
    { "heading": "community", "links": [discord (external), github (external), contributing, hello@hal0.dev] },
    { "heading": "data", "links": [benchmarks, roadmap] }
  ],
  "social": [ github, discord ]
}
```

(`learn`'s `match` needs to cover /docs, /blog, /changelog, /releases: change `match` to an array `["/docs","/blog","/changelog","/releases"]` and update `isActive` to accept `string | string[]`.) `nav.ts` adds `visibleHeader` (filters `hidden`), `footerColumns`, `subFor(path)` (returns the active header entry's `sub` or null). Tests updated: schema for `sub`/`hidden`/`footerColumns`, `isActive` array-match cases, mutual exclusion learn/benchmarks.
